# diffm-web

動画を比べるための Web ツールです。ブラウザだけで動き、動画はどこにも送信されません。

- **2つを比較**: 2本の動画を比べて、どこがどれだけ違うかをグラフにします。エンコード設定を変えたときの画質劣化や、編集で意図せず変わった箇所を見つけるのに使えます。音声も同時に比べて、グラフにして、聴き比べもできます。音声だけのファイル（mp3 / wav / flac / m4a など）も入れられます
- **複数を並べて再生**: 複数の動画を、横並び / 縦並びで、1本の共通タイムラインで同時に再生します

[Tsut-ps/diffm](https://github.com/Tsut-ps/diffm) の考え方を Web にしたものです。

## 使い方

### 2つを比較

1. A（基準）と B（比較対象）の枠に、動画をドロップするか、クリックして選びます（音声だけのファイルも入れられます）
2. 「解析開始」を押します。映像は 1 フレームずつ、音声は 1/30 秒ごとに比べます
3. 映像のグラフを押すと、そのフレームを A / B / 差分で見られます。押したまま動かすと、フレームが追従します
4. 音声のグラフで、波形の差・音量・周波数ごとの音量の差を見ます。「聴く」（Space）で、A / B / 差を聴き比べられます
5. 必要なら、画像（ZIP）や CSV で保存します

詳しくは、[映像の比べ方](docs/compare.md)と、[音声の差](docs/audio.md)にあります。

### 複数を並べて再生

1. 動画をドロップします（複数まとめて入れられます）
2. 右上で、並べ方（自動 / 横並び / 縦並び）を選びます
3. 下の再生バーで、全動画をまとめて操作します

詳しくは、[並べて再生](docs/player.md)にあります。

### 2つのタブの関係

動画を入れた側が「いまの作業」になり、もう一方のタブは初期状態に戻ります（「2つを比較」で A / B を入れると、並べて再生は、いまの A と B だけになります）。

## キー操作

<details>
<summary>キーの一覧</summary>

**2つを比較**

| キー | 動作 |
|---|---|
| ← / → | 前 / 次のフレーム（Shift で 10 フレーム。結果が出た後） |
| Home / End | 最初 / 最後のフレーム（結果が出た後） |
| Esc | 比較を止める（比較中） |
| Space | 音声を聴く / 止める（音声の分析が終わった後） |

**複数を並べて再生**

| キー | 動作 |
|---|---|
| Space | 再生 / 一時停止 |
| ← / → | 1 コマ戻る / 進む（Shift で 5 秒） |
| Home / End | 先頭 / 末尾 |
| M | すべてミュート |

</details>

## 動作環境と制約

- WebCodecs が使えるモダンブラウザが必要です。デコードできるコーデックはブラウザ次第（H.264 / VP9 / AV1 など）で、読めない動画は、読み込み時にエラーになります
- 解像度は、1 辺 4096px までです（4K UHD / DCI 4K を含む）。超えると、読み込み時に断ります

速さの目安は、[docs/performance.md](docs/performance.md) にあります。
