# 複数を並べて再生

複数の動画を、横並び / 縦並びで、1本の共通タイムラインで同時に再生します。

## 使い方

1. **動画を入れる**: ドロップします（「動画を追加」から選んでも可。複数まとめて入れられます）。「2つを比較」で A と B を読み込んでいれば、このタブを開いたときに、最初から入っています（フレームを選んでいれば、その時刻から始まります）。
2. **並べ方を選ぶ**: 右上の「自動 / 横並び / 縦並び」で切り替えます。
   - 自動は、画面と動画の形から、動画が大きく映るほうを選びます（初期値）。
   - 手動で選んだ並び方は、次回も覚えています。
3. **再生バーで操作する**: 全動画をまとめて操作します。

キー操作は、[README](../README.md#キー操作) にあります。

## できること

- 再生・一時停止、シーク、速度（0.25〜2 倍）、ループ、コマ送り（1/30 秒）
- 動画ごとのミュートと、まとめてミュート（音は最初の 1 本だけ鳴る状態で始まります）
- 動画ごとの「開始オフセット」: 別々に撮った動画のタイミング合わせに使います。単位は秒で、ドラッグでも変えられます（1px で 0.01 秒）。

## 制約

- 再生は `<video>` を使うため、再生できる形式は、ブラウザ次第です（mp4 / mov / webm など）。「2つを比較」で読めても、再生できない形式があります。
- 何本も同時に再生すると、端末の性能によっては、ずれることがあります。
- 音声だけのファイルは、このタブへ送られません。

## 同期

<details>
<summary>同期の仕組み</summary>

同期は、共通の時計に、各動画の再生位置を合わせて取ります。

- 再生を始めるときは、全動画が動き出すのを待ってから、時計を進めます（シーク直後は、キーフレームの間隔が長い動画ほど、動き出しが遅いため）。
- 再生中のずれは、次のように直します。
  - 0.03 秒以下: 放置
  - 0.2 秒まで: 再生速度を最大 ±15% 変えて解消（シークしないので、カクつかない）
  - それ以上: 位置を合わせ直す
- 一時停止・シーク・コマ送りのときは、全動画を同じ位置に揃えます。

</details>
