# 2つを比較

2本の動画を、先頭から順に 1 フレームずつ比べて、どこがどれだけ違うかをグラフにします。音声の差は [audio.md](audio.md) を見てください。

## 使い方

1. **動画を入れる**: A（基準）と B（比較対象）の枠をクリックして選ぶか、ドロップします。
   - ウィンドウのどこにドロップしても入ります（2本なら A → B、1本なら空いている枠へ）。
   - 入れ替えるときは、その枠に入れ直します。
   - 読み込むと、先頭フレームが枠に出ます。枠の下には、時刻と、ファイルの情報（解像度・fps・長さ・コーデック・音声）が出ます。
   - 音声だけのファイルも入れられます（[audio.md](audio.md#音声だけのファイル)）。
2. **「解析開始」を押す**: 「停止」を押すと、途中までの結果も使えます。
3. **グラフを見る**:
   - グラフを押すと、そのフレームを A / B / 差分で表示します。
   - 押したまま左右に動かすと、フレームが追従します（グラフの外へ動かしても、端まで追従します）。
   - しきい値を超えた区間は、色付きの帯で出て、ピークに印が付きます。区間にカーソルを合わせると、範囲とピークが出ます。
   - 見出しの ⏮ ⏭ で、前後の区間のピークへ移れます。
4. **保存する**:
   - 「画像を ZIP で保存」: 各区間のピークを PNG にします（左から A | B | 差分）。
   - 「CSV で保存」: 全フレームの値を保存します。

キー操作は、[README](../README.md#キー操作) にあります。

## 差分の値

画素ごとの色の差を、輝度で平均したものです。0 なら完全に同じで、最大は 255 です。しきい値以上が続く範囲を「区間」とします。

## 設定

設定（フレームの合わせ方、比較の解像度、差分の強調、しきい値）は、次回も覚えています。数値の欄（しきい値など）は、欄やその名前の上でドラッグしても変えられます（Shift で細かくなります）。

| 項目 | 内容 |
|---|---|
| フレームの合わせ方 | A のどのフレームと B のどのフレームを比べるか（下の表）。初期値は自動 |
| 比較の解像度 | 差分を計算するときに、縦横をこの割合に縮小する（50% なら画素数は 1/4）。小さいほど速く、細かい差は見逃しやすい。差分の枠の右に、実際に使った大きさが出る |
| 途中経過の更新 | 比較している最中に、差分の画像とグラフを描き直す回数。初期値の自動は、描くのにかかった時間に合わせる。回数が多いほど、比較は遅くなる（全フレームで半分ほど）。見逃したくないときは、全フレーム。結果の値には影響しない |
| 差分の強調 | 差分画像の表示倍率。値には影響しない |
| しきい値 | 「違う」とみなす値。終了後に変えると、区間もすぐ更新される |

### フレームの合わせ方

| 方法 | 内容 |
|---|---|
| フレーム番号 | A の n 番目と B の n 番目を比べる。どちらかが尽きたら終了 |
| 時刻 | A の各フレームの時刻に表示されている B のフレームを当てる（B は重複・欠落する） |
| 自動（初期値） | fps が違えば時刻、同じならフレーム番号 |

## 警告

比較条件が違うと、画面に警告を出します（比較は続行します）。

- 解像度が違う: B を A の大きさに拡縮します（縦横比が違えば引き伸ばします）
- fps が違う: 合わせ方に応じた注意
- 長さが違う: 短い方に合わせます
- 音声の条件が違うときの警告は、[audio.md](audio.md#注意点) にあります
