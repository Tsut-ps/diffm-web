# 音声の差

「2つを比較」の画面の、映像のグラフの下に出ます。音声がある動画のときに、「解析開始」で、映像と同時に分析します。

## 比べ方

- A と B の音声を、モノラルに混ぜて、1/30 秒ごとに比べます。
- 時刻は、各ファイルの先頭を 0 として揃えます（映像があれば先頭フレーム、音声だけなら音声の先頭）。音声の先頭が映像とずれている動画は、そのずれが差になります。
- 長さが違うときは、短い方までです。
- 見出しの右に、結果が出ます。「全体の差」は、A の音量に対する dB です。最大の差と、その時刻も出ます。完全に同じなら「差なし（完全に一致）」です。

### 音声だけのファイル

mp3 / wav / flac / m4a などの音声だけのファイルも、A・B の枠に入れられます。枠には「音声のみ」と出ます。

- A か B の**どちらかが音声だけ**のときは、映像は比べません。映像の欄（差分の枠・設定・映像のグラフ）を隠して、音声の差だけを出します。
- 片方だけが音声のときは、「音声だけなので、映像は比べません。」と警告します。

## グラフの見方

2 つのグラフが、同じ時間軸で並びます。

| グラフ | 内容 |
|---|---|
| **上: 折れ線** | **波形の差**（実線、オレンジ）: A − B の波形の大きさ（dBFS）。下にあるほど、近い音<br>**音量**（点線）: A（青）と B（赤）それぞれの音量（dBFS） |
| **下: スペクトログラム** | 縦が周波数（50 Hz〜20 kHz、対数の軸）、横が時間。色が、周波数ごとの**音量の差**（B − A）<br>青: A のほうが大きい / 赤: B のほうが大きい。濃いほど差が大きく、±24 dB で最大。たとえば、B のエンコードで高域が削られると、上のほうが青くなる |

### 何を見たいか

| 見たいこと | 見る場所 |
|---|---|
| 大きさが違うか | A・B の点線の離れ具合（重なっていれば、ほぼ同じ大きさ） |
| 音色が変わったか（高域の削れなど） | スペクトログラム。点線にはほとんど出ない |
| 厳密に同じか | オレンジの実線 |

点線は、単純な音量（実効値）です。耳の感度を考えたラウドネス（LUFS など）ではありません。

グラフを押す（押したまま動かす）と、その時刻を選び、動画のフレームも合わせます。動画側で選んだ時刻にも、音声の線が動きます。

## 聴く

「聴く」（Space）で、選んだ位置から 10 秒を鳴らします。

- **A / B / 差**を、再生中も切り替えられます。差は A − B で、小さいので、聞こえるまで自動で増幅します（倍率は表示されます）。
- グラフを押すと止まり、新しい位置を選べます。
- 並べて再生のタブへ移ると止まります。
- 聴くのは、モノラルに混ぜた音です。ステレオの左右の違いは、聴き比べられません。

## 保存

「CSV で保存」: 1/30 秒ごとの音量です（`time, level_a_db, level_b_db, diff_db`）。-96 dB は、それ以下（無音を含む）です。

## 注意点

<details>
<summary>折れ線の「波形の差」は、ずれに敏感です</summary>

- 波形の差は、A − B の波形の実効値です。**位相やサンプル 1 つ分のずれにも敏感**です。別々にエンコードした音（AAC の遅延など）は、聴こえ方が同じでも、大きく出ることがあります。
- スペクトログラムは、音の大きさだけを見るので、そういうずれに強いです。聴こえ方の違い（高域の削れ、音量の違い）は、こちらで見てください。
- 先頭の遅れを、自動で合わせる機能はありません。

</details>

<details>
<summary>分析の条件</summary>

- 周波数は 50 Hz〜20 kHz（対数）、窓は約 40 ms です。-90 dB より小さい成分は、無いものとして扱います。
- サンプルレートが違うときは、B を A に合わせて変換して（線形補間）比べます。高域に、変換による差が出ます。
- チャンネル数が違うときは、どちらもモノラルに混ぜて比べます。

</details>

<details>
<summary>音声が読めないとき</summary>

- 音声は、ブラウザがデコードできる形式（AAC / MP3 / Opus / FLAC など）だけです。
- 読めない音声は、「非対応」と出して、動画の比較だけ行います。音声だけのファイルが読めないときは、読み込みのエラーになります。
- 音声が片方だけにあるときも、音声の差は出しません。

</details>
